

# NexusAI Enterprise OS 🚀
> **Autonomous Multi-Agent Platform, AutoML Workbench, RAG Knowledge Hub & Natural Language BI Studio**

NexusAI Enterprise OS is an end-to-end, full-stack enterprise platform designed for autonomous multi-agent orchestration, automated machine learning model evaluation, high-performance RAG vector search, and natural language business intelligence.

---

## 🌟 Key Platform Modules

### 1. 🎛️ Control Center & System Telemetry
- **Live System Metrics**: Monitor real-time CPU/GPU load, memory overhead, active agent node status, and cluster uptime.
- **Orchestration Dashboard**: High-level telemetry of active agent workflows, system health indicators, and task execution throughput.

### 2. 🤖 Multi-Agent Fleet
- **Specialized Autonomous Cluster**: Features 8 domain-specific AI agents:
  - **Planner Agent**: Generates multi-step Directed Acyclic Graphs (DAGs) for complex tasks.
  - **Research Agent**: Queries vector databases for contextual RAG citations.
  - **Data Analyst Agent**: Inspects tabular schemas, distributions, and detects pipeline drift.
  - **ML Engineer Agent**: Benchmarks machine learning algorithm variants.
  - **Software Engineer Agent**: Auto-generates production REST API routers.
  - **Security Auditor Agent**: Audits token security, PII gates, and access policies.
  - **QA Test Agent**: Validates schema constraints and API unit tests.
  - **Executive Report Agent**: Synthesizes cross-agent results into C-suite briefings.
- **Interactive Execution Control**: Trigger agent tasks, view real-time log streams, inspect state transitions, and analyze agent delegation DAGs.

### 3. 🧪 AutoML Workbench
- **Model Evaluation Leaderboard**: Compare models across key metrics (Accuracy, F1-Score, Precision, Recall, Inference Latency).
- **Algorithm Variants**: Benchmarking across XGBoost, LightGBM, Random Forest, and Neural Networks.
- **Explainable AI (XAI)**:
  - Interactive SHAP feature importance breakdown.
  - Confusion matrix heatmap and threshold analysis.

### 4. 📚 RAG Knowledge Hub
- **Semantic Vector Search**: High-performance vector document retrieval with similarity scoring (HNSW / Cosine).
- **Sub-15ms Latency Tracking**: Real-time vector retrieval speed and top-k citation provenance.
- **Document Chunk Inspector**: Examine vector embeddings, metadata tags, and source document chunks.

### 5. 🔍 Natural Language SQL & BI Studio
- **NL-to-SQL Translation**: Converts plain English business questions into valid PostgreSQL queries.
- **Interactive SQL Query Editor**: Directly edit and run custom queries against connected databases.
- **Full Schema Inspector**: Displays all schema columns and sample rows with clean, full-visibility layouts.
- **PostgreSQL EXPLAIN Engine**: Generates realistic `EXPLAIN (ANALYZE, BUFFERS, VERBOSE)` tree output, including cost estimates, shared buffer hit ratios, and scan type badges (B-Tree Index Scan vs Parallel Seq Scan).
- **Dynamic Output Visualizers**:
  - **Table View**: Filterable data grid with CSV & JSON exports.
  - **Chart View**: Autogenerated Recharts graphic visualizations.
  - **EXPLAIN View**: Detailed cost and node performance analysis.

### 6. 💬 Agent Co-Pilot
- **Conversational Intelligence**: Interactive streaming co-pilot powered by Gemini for real-time task dispatching, system control, and data exploration.

### 7. 📄 Executive Report & Presentation Generator
- **Multi-Source Synthesis**: Combines agent outputs, AutoML leaderboards, and RAG citations into human-grade executive briefs.
- **3 Presentation Modes**:
  - **Executive Document**: C-suite formatted Markdown with styled tables, badges, and callouts.
  - **Presentation Deck Mode**: Interactive slide deck presentation with slide-by-slide navigation.
  - **Raw Markdown Source**: Live editor with export `.md` and copy capabilities.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Recharts, React Markdown, Remark GFM
- **Backend / API**: Express, Node.js, `esbuild`, `@google/genai` (Gemini API integration)
- **Database / Query Engine**: PostgreSQL-compatible schema and query execution engine
- **Build Tools**: Vite, TypeScript (`tsc`), Tailwind v4

## 🚀 Quick Start & Development

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
# Clone the repository
git clone <repository-url>
cd nexusai-enterprise-os

# Install dependencies
npm install
```

### Running in Development
```bash
# Start the full-stack server and Vite dev environment
npm run dev
```
The server will boot on `http://localhost:3000`.

### Building for Production
```bash
# Compile client assets and bundle server with esbuild
npm run build

# Launch production CommonJS server
npm run start
```
